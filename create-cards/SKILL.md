# Create Cards

When creating a matching-game card set:

1. Create exactly 6 pairs (12 cards total).
2. Use 6 distinct card identities.
3. Each identity must appear exactly twice.
4. Shuffle the 12 cards so matching cards are not grouped together.
5. Present each card individually.
6. Use simple symbols or emojis as the card identities.
7. Output only the 12 cards.
8. Do not create HTML, CSS, JavaScript, or other code.
